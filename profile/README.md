# B00 Games

**B00 Games** is an independent game development studio focused on atmospheric horror experiences.

We are currently developing our first title in **Unreal Engine**.

## Current Project

Our first project is an atmospheric horror game currently in early development.

Current development includes:
- Core interaction systems
- Inventory and item inspection
- Interactive door and key systems
- Story development
- Level design and environment blockout
